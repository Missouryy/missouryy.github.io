Research & Selected Projects

Cairn: Phase-Structured Agent for Complex Data Reasoning

SEU PALM Lab • Mar. 2026 – Jun. 2026

Research Assistant | Advised at Southeast University

Designed and built a SQL-first data agent using Qwen-3.5-35B-A3B on a forward-only four-phase finite-state workflow (SPEC → EXPLORE → DRAFT → REVIEW) rather than open-ended ReAct for heterogeneous table and document reasoning. Enforced workflow rules at runtime with phase tool allowlists and evidence quota gating. Built an evidence-grounding layer with a unified DuckDB catalog under a 150k token budget with priority-ordered eviction, fail-closed answer guards, and 3 parallel attempts merged by subset-aware numeric-convergence voting.

Benchmark Gain: 0.52 → 0.67 on 380+ tasks Text-to-SQL DuckDB State Machine Agent Qwen-3.5
